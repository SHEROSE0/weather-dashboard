# Weather Dashboard 🌦️

A sleek weather dashboard built with Python, Flask, Tailwind CSS, and the OpenWeatherMap API.

## Features
- Search current weather conditions for any city.
- Displays temperature, humidity, wind speed, and weather descriptions.
- Modern and responsive UI styled with Tailwind CSS.

## Overview
This application utilizes Flask as a backend server to fetch live weather data from the OpenWeatherMap API and presents it through a responsive Tailwind CSS frontend interface.
